# report-periodic

跨领域的周期性聚合器，支持周报与月报。

## 触发场景

- 用户说"生成本周周报""总结这个月"
- 定时任务在每周日 / 每月末触发

## 输入

- 周期类型：`weekly` 或 `monthly`
- 周期标识：周报用 ISO 周编号如 `2026-W41`，月报用 `2025-10`
- 数据来源：`data/daily/*.md` 与 `domains/*/data/*/*.json`

## 聚合指标

健康域：

- 作息：平均睡眠时长、平均入睡时间、平均睡眠评分、深睡占比趋势
- 运动：周 / 月总训练次数、总时长、总消耗、各类型占比、训练部位分布
- 饮食：日均热量摄入、日均蛋白质摄入、蛋白达标天数、三大营养素平均配比

## 输出结构

周报示例：

```markdown
# 周报 · 2026-W41（10-05 ~ 10-11）

## 概览
- 记录天数：7 / 7
- 平均睡眠：7h20m（评分 83）
- 训练次数：5 次，总时长 260 分钟
- 日均热量摄入：1820 kcal

## 趋势
- 睡眠时长较上周 +25 分钟
- 训练频率持平，力量训练占比提升

## 亮点与建议
- 蛋白质日均 118g，达标 6 天
- 建议：周末补充一次有氧

## 数据明细
（附表）
```

月报在周报基础上增加月度环比与关键里程碑回顾。

## 落库

- 周报写入 `reports/health/weekly/<YYYY-Www>.md`
- 月报写入 `reports/health/monthly/<YYYY-MM>.md`

> 投资域的周期报独立存放于 `domains/invest/reports/{weekly,monthly}/`，由 `invest-review` 生成，本 Skill 不写投资域。

## 注意事项

- 缺失数据不计入平均，并标注有效记录天数。
- 趋势判断需有数据支撑，样本不足时（如有效天数 < 3）标注"样本不足，仅供参考"。
