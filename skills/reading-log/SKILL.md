# reading-log

阅读记录。既记"读了多少"（页数、时长），也记"读到了什么"（要点、摘录），方便日后回看知识积累。

## 触发场景

- 用户说"今天读了《XX》30 页""看完了一本书""这段写得真好：……"
- 用户发来书页照片、阅读 App 截图、Kindle 划线

## 记录流程

1. 抽取书名，保持命名稳定（同一本书用同一个 `title`）。
2. 记录本次页数、时长、累计进度。
3. 若有笔记或摘录，提炼为要点写入 `highlights`。
4. 按 schema 写入 `domains/growth/data/reading/<YYYY-MM>.json`。

同一本书多次记录是允许的，每条是独立快照，便于累加总页数与时长。

## 输出字段

```json
{
  "metrics": {
    "title": "《深度工作》",
    "author": "Cal Newport",
    "pages": 60,
    "minutes": 45,
    "progress_pct": 40,
    "highlights": ["深度工作的稀缺性正在成为核心竞争力", "用固定日程对抗分心"],
    "rating": null
  }
}
```

`progress_pct` 与 `rating` 用户未提供时留 `null`。

## 用户向回报格式

```
阅读已记录 · 2025-10-09
《深度工作》· 60 页 · 45 分钟 · 进度 40%
要点：深度工作的稀缺性正在成为核心竞争力
```

## 注意事项

- 书名以用户表述为准，常见译名差异可记录别名到 `note`，不擅自统一。
- 要点提炼忠实原文，不加入个人发挥。
- 无法从照片识别书名或页码时，向用户确认。
