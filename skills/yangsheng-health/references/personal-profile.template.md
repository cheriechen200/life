# 个人健康档案（模板）

> ⚠️ **本文件是空白模板，不含任何真实个人数据。** 使用前请复制一份并自行填写，填写后的文件请勿提交到公开仓库。

## 使用方式

1. 复制本文件为 `personal-profile.md`（真实档案）：
   ```bash
   cp personal-profile.template.md personal-profile.md
   ```
2. 按自身情况逐项填写；不确定的字段留空，不要编造。
3. 将 `personal-profile.md` 加入 `.gitignore`，避免误提交。

> 若 `yangsheng-health` Skill 找不到 `personal-profile.md`，会回退到标准问诊流程，不影响使用。
