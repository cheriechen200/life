# 药食同源食材与四季食谱

## 一、核心食材功效表（滋阴润燥类 · 秋季重点）

| 食材 | 核心功效 | 最佳食用场景 |
|------|----------|--------------|
| 梨 | 清热生津、润肺止咳 | **生吃清热**；与**川贝蒸食**适合阴虚咳嗽；熬秋梨膏 |
| 银耳 | 滋阴润肺、养胃生津 | 羹汤，适合皮肤干燥、干咳；"平民燕窝" |
| 百合 | 润肺止咳、清心安神 | 肺燥干咳 + 心烦失眠（百合莲子羹） |
| 山药 | 补脾养胃、益肺生津 | 脾胃虚弱兼肺虚；煮粥、清炒、炖汤皆宜 |
| 鸭肉 | 滋阴养胃、利水消肿 | 阴虚体质首选肉类（优于羊肉、鸡肉之温） |
| 黑芝麻 | 补肝肾、润五脏、润肠燥 | 肠燥便秘、发枯；宜炒熟碾粉 |
| 蜂蜜 | 润肺止咳、润肠通便、调和诸药 | 温水冲服（**忌开水冲，破坏酶**）；燥秘 |
| 莲藕 | 清热生津、凉血止血 | 秋燥口渴；榨汁或炖汤 |
| 荸荠 | 清热生津、化痰消积 | 咽干口渴、肺热咳嗽 |
| 玉竹 | 养阴润燥、生津止渴 | 肺胃阴伤，干咳少痰 |
| 麦冬 | 养阴生津、润肺清心 | 泡水代茶，咽干、心烦失眠 |
| 桑椹 | 滋阴补血、生津润燥 | 阴虚血亏、肠燥便秘 |
| 甘蔗 | 清热生津、润燥下气 | 秋燥口渴（脾胃虚寒者少食） |

## 二、四季食材速查

- **春（养肝）**：山药、大枣、蜂蜜、韭菜、香椿、豆芽、枸杞、菊花、玫瑰花
- **夏（养心祛暑）**：绿豆、冬瓜、苦瓜、荷叶、乌梅、薏苡仁、赤小豆、西瓜（适量）
- **秋（润肺防燥）**：梨、百合、银耳、山药、莲藕、芝麻、核桃、蜂蜜、鸭肉、葡萄、柑橘
- **冬（温补肾阳）**：羊肉、牛肉、栗子、黑芝麻、核桃、韭菜、桂圆、生姜

## 三、秋季滋润食谱

### 1. 百合银耳莲子羹
**功效**：润肺安神，滋阴润燥。适合皮肤干燥、干咳、心烦失眠者。

**材料**：银耳 1 朵（约 15g 干品）、鲜百合 30g（或干百合 15g）、莲子 20g、冰糖适量、枸杞少许。

**做法**：
1. 银耳提前用冷水泡发 1-2 小时，去黄蒂，撕成小朵；莲子泡 30 分钟（去芯可减苦味）。
2. 银耳、莲子入锅，加足量清水，大火煮沸后转小火慢炖 60 分钟。
3. 加百合继续炖 20 分钟至银耳出胶、羹汤黏稠。
4. 入冰糖、枸杞再煮 5 分钟即可。

**要点**：银耳务必炖出胶质（胶质即有效成分）；小火慢炖是关键。

### 2. 杏仁雪梨瘦肉汤
**功效**：生津润燥，清热化痰。适合咽干、干咳少痰者。

**材料**：雪梨 2 个、南杏仁 10g、猪瘦肉 300g、无花果 3-4 枚（可选）、生姜 2 片、盐适量。

**做法**：
1. 雪梨洗净去核切块（**保留梨皮**润肺效果更佳）；南杏仁稍捣碎。
2. 猪瘦肉切块，冷水下锅焯水去血沫，捞出冲洗。
3. 所有材料入汤锅，加清水约 1.5L，大火煮沸后撇浮沫。
4. 转小火煲 1-1.5 小时，加盐调味即可。

**要点**：用南杏仁（甜杏仁）而非北杏仁；北杏仁有小毒须炮制且减量，家庭慎用。

### 3. 五汁饮（改良简易版）
**功效**：清热生津，润肺止渴。适合口干咽燥明显者。

**古方原版**：梨汁、荸荠汁、芦根汁、麦冬汁、藕汁（或甘蔗汁）五味合饮。

**改良简易版材料**：雪梨 1 个、莲藕 1 节、荸荠 5-6 个、麦冬 10g。

**做法**：
1. 麦冬加水 300ml 煮 20 分钟，取麦冬汁放凉。
2. 雪梨、莲藕（去皮）、荸荠（去皮）切块，一同榨汁。
3. 将榨得的汁与麦冬汁混合，可加少许蜂蜜调味，常温或微温饮用。

**要点**：脾胃虚寒、易腹泻者不宜多饮生榨汁，可温热后少量饮；现做现饮防氧化。

## 四、其他季节简易食养方

### 春季 · 枸杞菊花茶（养肝明目）
枸杞 10g + 菊花 5g，沸水冲泡代茶。适合眼干涩、春困。

### 春季 · 山药小米粥（健脾）
山药 100g 切块 + 小米 50g，同煮成粥。健脾和胃，四季皆宜，尤适气虚质。

### 夏季 · 绿豆薏米汤（清暑祛湿）
绿豆 50g + 薏苡仁 30g，加水煮至豆烂，少加冰糖。适合暑湿困重。

### 夏季 · 乌梅白糖汤（生津止渴）
乌梅 5-6 枚 + 白糖/冰糖适量，煮水代茶。汗多口渴时饮用。

### 冬季 · 当归生姜羊肉汤（温补气血，源自《金匮要略》）
羊肉 500g + 当归 15g + 生姜 30g，焯水后同炖 1.5-2 小时。适合阳虚质冬季进补。
**注意**：阴虚火旺、湿热质、感冒发热者忌用。

### 冬季 · 黑芝麻核桃糊（补肾润燥）
黑芝麻、核桃仁炒香碾粉，加热水调糊，可加少量蜂蜜。适合冬季肠燥便秘、发枯。

## 五、使用注意

- 药食同源食材虽平和，仍须**辨体质**选用（如虚寒体质少食梨、荸荠、甘蔗等性寒之品）。
- 涉及中药材（川贝、当归、麦冬、玉竹等）时，提醒用户：**建议咨询中医师**；孕妇、哺乳期、慢性病患者、正在服药者尤须谨慎。
- 食疗起效缓和，适合亚健康调理；急症、重症须就医。
