# 基金产品分类与身份判定

## 分类枚举

统一字段 `product_category`：`equity`（权益类）、`bond`（债券类）、`money_market`（货币市场基金）、`qdii`（境外投资）、`fof`（基金中基金）、`gold_fund`（黄金基金）。

可选 `product_subcategory` 进一步说明权益产品的 `index` / `hybrid` / `active_equity` 等具体类型；不得将“指数/混合”误作为与 `product_category` 并列的新枚举。若一个产品兼具跨境或黄金主题，应优先按基金合同/主要投资策略选择类别，必要时将其他属性写进说明，不要双重分类。

## 产品身份必须靠证据确认

1. 代码以字符串保存，通常为六位数字。格式只用于发现录入错误，不证明它是基金代码。
2. 至少交叉核对基金全称与代码，并确认场外销售平台/份额类别；优先支付宝页面、基金管理人页面或基金合同信息。
3. A/C/E 等份额类别往往对应不同费用或费率结构。未见账户页面/合同证明时，不自行补类别或把一个类别的费用套到另一个类别。
4. 产品身份确认后可登记于 `domains/invest/fund_universe.json`；只登记有证据支持的映射，不导入股票 `universe.json`。
5. 代码与名称不一致、重名、截图模糊、或用户只发六位数字时，停下询问，不查询同号 A 股，也不自动拼股票市场前缀。

## 场内外分界

- 支付宝场外开放式基金、余额宝/货币基金、QDII、FOF、场外黄金基金及黄金 ETF 联接走 `fund-*`。
- 场内股票、ETF、LOF（含场内黄金 ETF）走 `invest-*` 股票链路，其证券代码、交易时点和费率规则由股票侧处理。
- 账户金、积存金、实物黄金不是基金，不在本期台账 Schema 内。

## 口径分离

| 对象 | 合适指标 | 不可混淆 |
|---|---|---|
| 权益 / 债券基金 | 区间净值收益、基准差异、回撤、风险暴露 | 基金净值收益与指数/股票价格收益不是同一口径 |
| 货币基金 | 每万份收益、七日年化、用户实际到账收益 | 七日年化不是承诺收益，也不是持有期实际收益 |
| QDII | 基金净值及日期、基准、外汇影响、市场休市 | 海外市场收盘日、人民币净值日与支付宝页面日期可能错位 |
| FOF | FOF 净值、底层基金暴露、费率层次 | 缺少持仓穿透时不可宣称已消除底层重叠 |
| 黄金基金 | 基金净值、基准/母 ETF、黄金与汇率暴露 | 黄金现货、期货、ETF 价格与基金净值不可直接视作同一序列 |

分类无法确定时采用“未确认”并澄清，不要把最像的类别强行写入数据。
