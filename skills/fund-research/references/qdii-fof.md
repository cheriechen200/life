# QDII 与 FOF 专项口径

## QDII：时差、汇率与净值披露

1. 标记基金 NAV 日期、底层市场交易日期、北京时间披露日期与用户提交订单日期，避免把跨市场时点错位解释成异常涨跌。
2. 确认基准币种和基金份额计价币种；区分底层市场回报、汇率影响、基金费用及跟踪偏离。无可靠分解数据时只列因素，不编贡献值。
3. 核对境外市场休市、节假日、限购/暂停申购、估值调整与临时公告；不得把前一海外交易日净值写作“今天实时净值”。
4. ETF/QDII 场内价格若被用户提及，先确认是场外 QDII 基金还是场内证券产品；两者分路由，不能将场内溢价等同场外净值。

## FOF：穿透与费用

1. 查定期报告和基金公司披露的底层基金、资产类别、披露日期及穿透比例。
2. 只有底层明细完整度足够时才讨论行业/资产重叠；披露不全则明确“未完全穿透”，不把未知当作零暴露。
3. 费用分析分别呈现 FOF 自身费用、底层基金费用和可能豁免/折扣条款。确认适用合同与计费方式后再估算，不对已体现在净值中的费用重复扣减。
4. 绩效评价要识别多资产配置目标与比较基准，不只拿权益指数对比，也不因基金组合分散就宣称低风险。

## 共通输出

同时给出 NAV 及其日期、对应市场日期、币种/汇率口径、披露滞后和关键缺口。缺少最新披露时使用最近已披露数据并写出数据截至日，不外推为当前持仓。
