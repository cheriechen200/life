# 基金咨询与记录输出模板

## 单只基金咨询

```text
结论：<直接回答用户问题；标明判断置信度与适用边界>
身份：<名称 / 代码 / 份额类别 / 类别 / 平台；身份未确认项明确标注>
依据：<指标或披露内容｜统计期间 / NAV 日期｜来源>
主要风险：<最相关的类别风险、费用或时点限制>
反向条件：<哪些可观察信息会推翻当前判断>
缺口：<无法取得 / 用户尚未提供的信息>
```

## 基金比较

比较前确认份额类别、统计周期、净值/分红口径、基准、币种、费用和风险等级可比。表格中每只基金均给代码；数据时点与来源在表头/脚注注明。无法量化的字段使用“未披露/未核验”，不要给伪精确排名。

| 基金（名称 + 代码） | 类别/策略 | 对比期间与 NAV 日期 | 相对基准 | 费用口径 | 关键风险 | 证据/缺口 |
|---|---|---|---|---|---|---|

## 账户事实回报

```text
基金持仓/交易已更新 · <申请日或快照日>
识别：<基金名称 + 代码 + 份额类别>
已确认：<只列截图/用户确认字段>
待确认：<模糊或缺失字段；未写入的字段>
写入：<JSON / 台账路径>
```

## 基金研究笔记字段

笔记至少含 `thesis`、`fund_code`、`fund_name`、`platform`、`product_category`、`evidence`、`risks` 与可验证的 `kill_criteria`（证据不足时可说明暂无法定义）。研究咨询仅在用户明确要求保存时输出 JSON 记录。
