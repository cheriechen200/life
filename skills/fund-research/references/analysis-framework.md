# 基金研究框架

## 研究顺序

1. **身份与问题**：确认基金代码、名称、份额类别、平台、类别和用户关注的持有期限；逐项避免同代码误配。
2. **投资目标与策略**：以基金合同、招募说明书和定期报告为准，确认投资范围、基准、策略、资产约束及风险等级。产品名称不是策略证据。
3. **净值与相对表现**：明确净值日期、统计区间、复权/分红口径、份额类别和比较基准。使用相同区间、币种及收益口径；指数基金看跟踪表现，主动基金看相对基准且注意经理任期。
4. **风险**：按类别分析波动/回撤、权益暴露、利率/信用、汇率/海外市场、底层基金重叠或黄金基准差异。缺少持仓穿透时写明不可见，不由基金名称推断。
5. **成本与流动性**：核对实际份额类别的申购折扣、赎回费持有期限阶梯、管理费、托管费、销售服务费和到账规则；未知费率明确缺口。
6. **产品适配**：先询问/注明期限、流动性需求、亏损承受能力、投资目的和现有重复暴露。没有这些信息时只做产品层面的研究，不给用户画像结论。
7. **结论与反证**：给观点及置信度，列出支持证据、最重要的反向风险、能推翻判断的可观察条件，以及仍缺哪些信息。

## 区间收益与净值口径

- 核对收益周期的起止日期与净值可用日；当最新 NAV 未披露时用最近可用日期，并明确说明滞后。
- 区分累计净值、单位净值、分红再投资总回报及页面“持有收益”。只有口径匹配时才比较。
- 对比至少使用基金自身基准或策略匹配基准；不拿单一时间点涨跌推断长期能力。
- 用用户截图记录的收益时，标明这是账户展示值而非独立测算；对不上时先复核日期、分红、份额类别与费用。

## 风险识别框架

| 风险类型 | 核查重点 | 数据缺口处理 |
|---|---|---|
| 权益 / 混合 | 行业、风格、集中度、基准偏离、回撤 | 缺最新定期报告时标明数据截至日 |
| 债券 | 久期、信用等级、行业/发行人集中度、利率敏感性 | 不把“债基”直接等同低风险或保本 |
| 货币 | 流动性、收益下行、赎回限制 | 不用七日年化推算未来到账收益 |
| QDII | 海外资产、币种、市场时差、假期、限购/溢价影响 | 区分估值与正式 NAV |
| FOF | 底层基金、穿透比例、重复持仓、双层费率 | 未披露的穿透项标为未知 |
| 黄金 | 基准与工具、跟踪偏离、衍生品/汇率 | 不把现货金涨跌等同基金收益 |

## 事实等级

输出应区分：基金公司/基金合同事实；监管披露事实；第三方平台二手数据；用户截图；分析推断；未验证假设。对二手信息标明来源和日期，不用确定语气掩盖口径差异。
