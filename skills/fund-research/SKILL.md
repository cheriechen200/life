# fund-research

## 目的

为支付宝场外基金及黄金基金提供产品分类、研究流程、数据来源、费用和专属风险口径。复用股票研究的“核心方法论 + 按需 references”结构，但**不复用股票指标与交易规则**。本 Skill 不写持仓/交易数据。

## 研究流程

1. **确认产品身份**：核对基金代码（字符串）、全称、份额类别、平台及产品类别；到 `domains/invest/fund_universe.json` 检查是否已有经确认的身份记录。目录没有映射时，先用用户页面和基金管理人/正式产品资料核验，确认后登记身份及来源；名称或代码冲突时停下澄清，不调用股票接口。
2. **确定用户问题**：区分产品类别、风险、表现、费用、持有状态、适配性或产品比较；不要把概念解释伪装成个性化买卖建议。
3. **按需加载方法论**：所有任务先读 `references/product-taxonomy.md`、`references/data-sources.md`；根据品类增加 `analysis-framework.md`，以及 `money-market.md`、`qdii-fof.md`、`gold-fund.md` 或 `fee-rules.md`。输出前按需读 `output-templates.md`。
4. **取数并校验时点**：涉及具体基金、净值或业绩时先通过 `domain_search` 获取金融数据；如工具不可用或覆盖不足，再使用公开网页检索并注明媒体/平台及日期。优先基金管理人、基金合同、定期报告等一手披露，第三方数据须标二手来源。记录指标对应净值日/统计期、发布时间、来源链接和口径。不可用股票行情接口替代基金净值。
5. **分析且保留反证**：区分事实、管理人披露、第三方数据、估算与判断；结论至少覆盖用户所问维度、最关键风险和能推翻判断的条件。无法取得证据时明确缩小结论，不补造收益、持仓或费率。
6. **遵守品类口径**：货币基金的万份收益/七日年化与净值收益不可直接混比；QDII 考虑海外休市、汇率及披露时差；FOF 检查双层费用与底层重叠；黄金基金分离基金净值、跟踪基准与底层黄金敞口。
7. **不套股票交易规则**：场外基金净值并非盘中可交易价格，不给日内止损价、盘口技术信号或 5 元佣金规则。讨论操作时，先列出仍缺失的期限、风险承受度、资金安排和持有状态等前提，并明确申赎确认及费用约束。
8. **输出免责声明**：如给出具体投资建议、操作条件或仓位调整建议，回答末尾逐字使用固定免责声明：

> **免责声明**：以上内容基于公开数据和量化分析，仅供参考，不构成投资建议。市场有风险，投资需谨慎。任何投资决策应结合个人风险承受能力、资金状况和投资目标独立判断，必要时咨询持牌专业机构。过往表现不预示未来收益。

## References

- `references/product-taxonomy.md`：产品类别、场内外边界和身份识别。
- `references/analysis-framework.md`：收益、基准、风险、组合适配研究步骤。
- `references/fee-rules.md`：申购、赎回、管理托管及销售服务费核对。
- `references/money-market.md`：余额宝/货币基金指标与确认时点。
- `references/qdii-fof.md`：海外市场时差、汇率、FOF 穿透及双层成本。
- `references/gold-fund.md`：黄金基金、ETF 联接、基准与敞口去重。
- `references/data-sources.md`：来源优先级、时点和缺失处理。
- `references/output-templates.md`：咨询、比较与数据缺口表达模板。

## 边界

- 不更新 `fund_holdings.md` 或基金 JSON；记录用户账户事实时转给 `fund-position`。
- 不默认沉淀研究笔记；只有用户明确要求保存时转给 `fund-note`。
- 不把同属 `invest` 解释为基金自动进入股票报告、总资产视图或 dashboard。
- 缺乏已核实的外部数据时，如实说明当前数据源不覆盖，并提供可执行的下一步核对项。
