# invest-morning

每日投资简报生成器。领域是动态的，只要数据遵循统一 schema，本 Skill 无需修改即可包含新数据。

## 触发场景

- 用户说"生成今天的简报""今日投资建议"
- 定时任务在每日固定时间触发（建议 09:00，或在收盘后 15:10 生成「收盘定稿版」）

> **定时任务的调用提示词见 [`automations/invest-morning.md`](../../automations/invest-morning.md)**（调度、路径、落盘、失败处理）。本文件只定义**分析流程**，调度口径改那边。

## 输入

- 目标日期，默认今天
- 数据来源：`domains/invest/data/*/<YYYY-MM>.json` 中 `date` 等于目标日期的记录
- 持仓台账：`domains/invest/holdings.md`
- 行情 / 资金 / 资讯：见 `stock-research/references/data-sources.md`

## 生成流程

1. **前置**：读 `skills/stock-research/SKILL.md` + `references/`，读 `domains/invest/universe.json`。
2. **读持仓**：从 `holdings.md` 与 `positions/当月.json` 取当前持仓、成本、可用数量、现金。
   - **无成本价 / 持仓数量 → 不输出任何加减仓指令**，只给新建仓建议与止损位，并把缺口写进「待用户确认」。
3. **刷行情**：指数 + 持仓标的 + 候选池，取收盘价、涨跌幅、成交额、5/20/60 日走势、52 周分位。
4. **扫信息面**：过去 24 小时，按利好 / 利空 / 中性分档，只保留与持仓 + 候选池相关的。
5. **三维分析**：基本面 / 技术面 / 信息面（口径见 `stock-research/references/analysis-framework.md`）。
6. **出结论**：每个标的给明确行动分类 + 一句核心理由 + 关键风险；推荐 1–3 只，含仓位上限与止损位。
7. **渲染**：按 `stock-research/references/output-templates.md` 的简报模板输出。
8. **落盘**：写入 `domains/invest/reports/daily/<YYYY-MM-DD>.md`。
9. **回写台账**：更新 `holdings.md` 的持仓表 / 观察池表 / 变动日志，变动行标更新日期。
10. **水位**：更新 `domains/invest/.brief_state.json`，**同日已生成则提示覆盖确认，不静默重复生成**。
11. **规范化**：运行 `python3 scripts/normalize_invest_data.py`。

## 简报五节结构

| 节 | 内容 | 硬性要求 |
| --- | --- | --- |
| 一、市场速览 | 大盘 / 板块 / 资金面，各 1 条 | 3 条以内，每条带数字 |
| 附：信息面扫描 | 24h 事件按利好 / 利空 / 中性分档表 | 每条带来源与时间 |
| 二、今日推荐 | 标的 / 类型 / 现价 / 逻辑 / 仓位上限 / 止损 / 风险 | 1–3 只 + 「明确的回避项」表 |
| 三、持仓动态 | 标的 / 成本 / 现价 / 盈亏% / 今日建议 / 触发原因 | 附观察池表；无持仓时明确说明无法计算 |
| 四、风险提示 | 当日最重要的 3 条 | 必须量化 |
| 五、数据来源与缺口 | 来源表 + `[MISSING]` / `[STALE]` 清单 | 逐条列，不藏 |

## 今日小结生成规则

- 汇总关键数值：指数涨跌、成交额、主力资金方向、持仓盈亏。
- 结合用户目标给出 1–3 条针对性建议，每条带数据依据。
- **语气客观，不做收益承诺**。
- 数据缺失时明确标注"未记录"，**不要编造**。

## 降级版

若当日检索失败或数据严重缺失：

1. 如实报告缺口，列出具体失败项；
2. 输出**降级版简报**（只保留能确认的数据 + 明确的缺口清单）；
3. **绝不编造**数字、来源或事件。

## 注意事项

- 简报只做聚合与呈现 + 回写台账，**不修改历史数据文件**。
- 若同一天有多条同类记录，全部列出，不要覆盖。
- **标的池铁律**：推荐生成后必须复核一遍代码前缀（读 `universe.json`），防止违规标的流出。
- 港股 / 港股通标的不得出现在推荐中；港股新闻只能出现在信息面。
- 结尾固定标注：「本简报仅供研究参考，不构成个人投资建议，投资有风险，决策需独立。」
