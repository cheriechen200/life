# medical-report

体检 / 检验检查报告的结构化解析。用于把一次体检的零散数值变成可比对的长期数据，同时避免把「在服肌酸」「高蛋白饮食」「训练后」造成的生理性波动误读成器官问题。

## 触发场景

- 用户发来体检报告、检验单、检查报告照片（血常规、尿常规、生化、心电图、DR/CT/超声报告单）
- 用户说「这是我今天的体检报告」「帮我看看化验单」「记录一下这次检查结果」

## 边界铁律（不可逾越）

1. **不下医学诊断、不开药、不给治疗方案**。只做：数值摘录、相对参考范围的高/低标注、与本人既往数据的趋势对比、与训练/饮食/补剂的关联说明。
2. **影像结论以放射科 / 超声科报告原文为准**。本 Skill 只对「影像所见 / 印象」做结构化摘录与术语归档，**不自行判读影像、不自己量 Cobb 角**。
3. **异常项一律提示由医生复核**，尤其：心电图结论异常、QTc 异常、尿蛋白/尿潜血阳性、肝酶显著升高、血肌酐/eGFR 异常、血脂显著异常、影像提示结构性改变。
4. **数值不可辨认时留空并列出缺失项**，**严禁凭经验或「常见值」填数**。宁可少记一项，不可记错一项。
5. **只入库结构化数值，不入库身份信息**：姓名、身份证号、病案号、条码号等**一律不写入** `domains/`。原始图片存 `data/raw/<日期>/`（已被 `.gitignore` 排除，不 commit、不 push）。

## 解析流程

1. 先确认**检查日期**与**机构**（报告右上角一般有采样时间 / 检查日期；无则以用户口述为准）。
2. 按**语义定位**读各 panel，不按固定坐标硬读。OCR 与图片描述都会出现数字错位，**以图中印刷值与其所在行列为准**。
3. 每项必须同时抓到：**项目名中文、数值、单位、参考范围**。四者缺一则该项标 `flag = unknown`，不猜。
4. 判定 `flag`：低于下限 `low` / 范围内 `normal` / 高于上限 `high` / 报告已加箭头或「危急值」标记 `critical_low` / `critical_high`。
5. 文本型结论（心电图结论、影像所见与印象）进 `findings`，**原文摘录、不改写**。
6. 跑交叉校验（见下）。
7. 写 `domains/health/data/medical/<YYYY-MM>.json`；需要长文解读时另写 `reports/health/topics/体检解读_<YYYY-MM-DD>.md`。
8. 跑 `python3 scripts/normalize_health_data.py` 刷新看板。

## 强制交叉校验（落库前必做）

沿用 `body-comp` 的教训（2025-MM-DD 事故：二手转录四项全错、错误数据被下游引用两周）：

| 校验 | 说明 |
| --- | --- |
| **逐项回原图复核** | 凡有原始照片，一律对照原图直读，**不要凭摘要、记忆或「上次的值」二次转写** |
| `flag` 与参考范围自洽 | `value` 落在 `[ref_low, ref_high]` 内却标了 `high`，或超出却标 `normal` → 不许落库 |
| 单位与参考范围单位一致 | 如 Cr 的 μmol/L 与 mg/dL、TG 的 mmol/L 与 mg/dL，**混用会让数值差一个量级**；不确定就在 `note` 标「单位待确认」 |
| 派生项互校 | `AST/ALT ≈ AST ÷ ALT`、`A/G ≈ ALB ÷ GLOB`、`IBIL ≈ TBIL − DBIL`、`non-HDL ≈ TC − HDL-C`（容差 ±10%） |
| 血常规内部互校 | `中性粒绝对值 ≈ WBC × 中性粒%`；`HCT ≈ RBC × MCV / 10`（粗校，容差 ±10%） |
| 数值合理性 | 与本人既往值（读 `domains/health/data/medical/` 历史月份）差异超 50% 时，先在 `note` 标「与既往差异大，待复核」，不要直接落库当事实 |

**读不到图时的处理**（2025-MM-DD 事故）：若当前会话**无法读取图片内容**，必须：① 明确告知用户；② 只记录能确认的信息；③ 无法确认的项写 `null` 并在 `note` 末尾用「**待确认**：…」列出；④ **绝对不能**用「这类报告通常是 x」来填数。


| 字段 | 说明 |
| --- | --- |
| `panel` | 分组标识，见下表 |
| `name` | 稳定英文标识（长期趋势比对用） |
| `value` | 数值；文本型结果（阴性/阳性、±）存 `ref_text` 与 `comment`，`value` 留 null |
| `ref_low` / `ref_high` / `ref_text` | 报告印刷的参考范围；只给文字时填 `ref_text` |
| `flag` | `low` / `normal` / `high` / `critical_low` / `critical_high` / `unknown` |
| `findings` | 文本型结论（心电图、影像），**原文摘录** |
| `abnormal` | `flag` 非 `normal` 的项汇总，方便日报与看板直接读 |
| `fasting` | 是否空腹采血（影响 TG、血糖解读） |

## 分组与指标清单（panel 取值）

| panel | name_cn | 常见指标（`name`） |
| --- | --- | --- |
| `blood_routine` | 血常规（五分类） | `wbc`、`neut_pct`、`lymph_pct`、`mono_pct`、`eos_pct`、`baso_pct`、`neut_abs`、`lymph_abs`、`mono_abs`、`eos_abs`、`baso_abs`、`rbc`、`hb`（血红蛋白）、`hct`、`mcv`、`mch`、`mchc`、`rdw`、`plt`、`mpv` |
| `urine` | 尿液分析 / 尿常规 | `sg`（比重）、`ph`、`pro`（蛋白）、`glu`（糖）、`ket`（酮体）、`uro`（尿胆原）、`bil`（胆红素）、`bld`（潜血）、`leu`（白细胞酯酶）、`nit`（亚硝酸盐）、`vc`、`microalbumin`、`acr`；镜检 `rbc_hpf`、`wbc_hpf`、`cast` |
| `renal` | 肾功能 | `cr`（肌酐）、`bun`（尿素氮）、`ua`（尿酸，也可单列 `uric_acid`）、`egfr`、`cysc`（胱抑素C）、`b2mg`、`co2cp`、`glucose`（若血糖在生化套组内） |
| `liver` | 肝功能 | `alt`、`ast`、`ast_alt_ratio`、`ggt`、`alp`、`tbil`、`dbil`、`ibil`、`tp`、`alb`、`glob`、`ag_ratio`、`tba`、`ldh` |
| `lipid` | 血脂 | `tc`、`tg`、`hdl_c`、`ldl_c`、`non_hdl`、`apo_a1`、`apo_b`、`apo_b_a1`、`lp_a` |
| `imaging` | 影像（X 光 / CT / 超声） | 数值项极少，结论进 `findings` |
| `ophthalmology` | 眼科（眼压 / 电脑验光 / 角膜曲率） | `iop_right`、`iop_left`、`ref_right_s/c/a/se`、`ref_left_s/c/a/se`、`pd_mm`、`krt_right_ave_d/mm/cyl`、`krt_left_ave_d/mm/cyl` |
| `other` | 报告内未涵盖的项 | 兜底，按报告原文命名 |

**心电图**（归入 `findings`，`modality = ecg`）：`rhythm`（节律）、`hr_bpm`、`pr_ms`、`qrs_ms`、`qt_ms` / `qtc_ms`、`axis`（电轴）、`st_t`（ST-T 描述）、`impression`（结论原文）。
**脊柱全景 X 光**（`modality = xray`，`region = spine_full`）：检查方法（站立全脊柱正/侧位）、`cobb_deg`（**仅在报告已给出时填**，不自测）、`curvature`（生理曲度）、`alignment`（序列/侧弯）、`vertebral_body`、`disc_space`、`bone_density`、`impression`（结论原文）。

## 针对本人的交叉解读口径（写 `comment` 时必须套用）

这几条是本 Skill 的核心价值——**把生理性波动与病理性异常分开**，避免误读：

| 情形 | 解读口径 |
| --- | --- |
| **血肌酐 Cr / eGFR** | 用户**在服一水肌酸**（近期 1.8–4.5 g/天）。肌酸代谢会产生肌酐，使血清 Cr **假性升高约 10–25 μmol/L（0.1–0.3 mg/dL）**、eGFR 相应被低估。**Cr 轻度偏高不等于肾功能下降**，必须在 `comment` 注明「在服肌酸」；若要得到干净的肾功能基线，需在医生指导下停用肌酸约 7 天后再测（**提示，非医嘱**）。胱抑素 C（不受肌酸影响）若同时测了，是更可靠的对照 |
| **尿素氮 BUN** | 蛋白目标 150 g/天 + 乳清蛋白粉，**高蛋白摄入会升高尿素氮**，单独升高且 Cr/胱抑素C 正常时多属代谢负荷的正常反映 |
| **尿酸 UA** | 高蛋白 + 海鲜（鱿鱼）+ 含糖饮料是升高因素；只标注数值与趋势、提示医生复核，**不诊断痛风/高尿酸血症** |
| **肝酶 ALT / AST** | **力量训练后 24–72 小时内 AST、CK、LDH 可升高**（肌肉来源），AST 升高不等于肝损伤；ALT 对肝脏相对更特异。若 AST↑ 而 ALT 正常、GGT/胆红素正常，优先提示「需排除训练后肌肉来源」，并建议复查前停训 48–72 小时 |
| **血脂** | 规律训练通常升高 HDL-C、降低 TG。结合薄肌减脂目标解读：HDL-C 偏低 / TG 偏高时提示复查与生活干预，**不给降脂药建议** |
| **尿常规** | 近期饮水完成度偏低（38%–52%），尿比重偏高、尿色深属浓缩表现；**尿蛋白/尿潜血阳性必须提示复查**（留中段尿、避开训练后 24–48 小时，因剧烈运动可致一过性蛋白尿/血尿） |
| **血常规** | 嗜酸/嗜碱比例轻微波动通常无临床意义；只标注明显异常，不做血液学推断 |
| **心电图** | 可与 `daily_metrics.resting_heart_rate`（Apple 健康）对比静息心率；**QTc、ST-T、节律异常一律提示心内科复核**，本 Skill 不做心电图诊断 |
| **脊柱 X 光** | 与深蹲 / 硬拉 / 划船等负重动作相关：若提示侧弯、曲度变直、椎体或椎间盘改变，训练动作选择需咨询医生或康复师；**影像结论以放射科报告原文为准** |

### 医生面诊确认口径（2025-MM-DD，用户转述西医意见，解析同类报告时优先套用）

1. **肌酐升高**：原因 = 剧烈运动 + 肌酸 + 蛋白质摄入过量；**反复升高会伤肾，需重视**。处理 = 减蛋白/减肌酸 + 增饮水，并复查确认趋势。不要只写「补剂假性升高、无需处理」——要按「需干预」归档。
2. **窦性心动过缓伴不齐**：窦性心律本身是正常心律；年轻男性躺卧迷走神经兴奋时 50–60 bpm 常见，运动员可低至 30–40。**无症状（心慌/胸闷）无需处理**，规律作息少熬夜即可；有不适才复诊。
3. **HDL-C 偏高**：「好胆固醇」，年轻人偏高无需担心，随年龄增长会回落。
4. **淋巴细胞百分比略高、总数正常**：无大碍，不处理。
5. **尿液味重色黄**：蛋白分解（氨）多 + 饮水少；比重未达浓缩上限时暂无大碍，处理 = 控蛋白 + 增饮水。
6. **口干/口苦/白痰**：口干考虑夜间张口呼吸；口苦考虑胆汁反流（饭后立即窝躺是主要诱因，B 超与非发作期胃镜难查出），处理 = 饭后 1 小时不窝不躺。症状归档至体检解读长文，不做检验关联推断。

## 用户向回报格式

先给异常项，再给关联解读，最后给需就医复核的项：

```
体检已记录 · 2025-MM-DD · 共 38 项，异常 4 项
偏高：尿酸 452 μmol/L（参考 208–428）
偏低：HDL-C 1.00 mmol/L（参考 1.04–1.55）
需医生复核：尿酸偏高、尿潜血 ±（建议留中段尿复查，避开训练后 48h）
与训练/补剂相关：肌酐 92 μmol/L 在参考范围内，但你在服肌酸，数值会假性偏高，胱抑素C 正常可佐证肾功能
以上仅为数据整理与趋势提示，不构成医学结论，异常项请由医生复核。
```

## 注意事项

- 报告里的参考范围**以报告印刷值为准**，不要用「通用成年男性参考值」覆盖；不同机构范围不同，抄错会让 `flag` 反向。
- 一次体检若分多张报告（检验单 + 心电图 + 影像），**同一 `date` 下可写多条 `medical_report` 记录**，按 `panel` 或 `modality` 区分，不要合并成一条。
- 只改自己写入的记录，**不修改任何原始数据文件**；已入库的同一份报告不要重复写（比对 `source` 或 `exam_date + panel`）。
- 长文解读放 `reports/health/topics/体检解读_<YYYY-MM-DD>.md`，日报里只做一行摘要 + 链接。
- 记录后跑 `python3 scripts/normalize_health_data.py`。
