# training-review · 训练周复盘

方法论口径见 [`reports/health/topics/训练方法论参考_2025-10-19.md`](../../reports/health/topics/训练方法论参考_2025-10-19.md)（提炼自 openGym，仅取思路不搬代码），本 Skill 是它的执行入口。

## 触发场景

- 定时任务每周日触发（与 `训练排期_*.md` 的「每周日回看」一致）
- 用户说「复盘训练」「本周训练怎么样」「下周怎么练」

## 输入

- `domains/health/data/workouts/<YYYY-MM>.json` 中本周（周一至周日）的 `workout` 记录
- 当期排期文档（最新的 `reports/health/topics/训练排期_*.md`）与方案文档
- 动作参考库 `domains/health/reference/exercise_ref.json`（动作 → 肌群归属）

## 分析流程

1. **汇总本周**：列出每次训练（时间 / 类型 / 时长 / 消耗 / 部位），力量训练逐动作汇总组数、`volume_kg`（有明细时；缺失的在「数据缺口」注明，不推算）。
2. **肌群三问**（来自方法论参考第四节）：
   - 容量去了哪：分肌群组数 / 容量分布；
   - 还在恢复吗：同一大肌群两次大重量间隔 <48h 标恢复不足；
   - 有什么没练：对照 `body_parts` 全集找零容量肌群。
3. **渐进检查**：对有完整组数明细的动作，先判定上次同动作是 hit 还是 miss（勾选且组数次数均达标 = hit；次数不足 / 组数不足 / 未勾选 = miss，高开低走一律算 miss），再套用策略清单（linear / greyskull / double 双渐进 / triple 三渐进 / time）与降载规则（连续 3 次 miss 降载 10%，greyskull 为失败 1 次即降载）。明细不足时只比较 `weight_kg` 最大组，并注明口径。
4. **平衡提示**（可选）：按方法论参考第五节的锚动作模板（Poliquin / Thibaudeau / ATG），若某主项明显低于其锚动作对应比例，提一句「建议补 X」，不作结论。

## 输出格式

```
# 训练周复盘 · 2026-W43（MM-DD ~ MM-DD）
## 本周训练（N 次）
- MM-DD 肩部力量 35min / 202 kcal：侧平举 3×12 @5kg …
## 肌群三问
1. 容量分布：背 X 组 / 腿 Y 组 / …
2. 恢复：…（无则写「无连续大重量间隔不足」）
3. 空白：…（本周零容量肌群）
## 渐进检查
- 深蹲 80kg 4×10 达成 → 建议 10-20 加至 82.5kg（+2.5kg 线性）[依据：MM-DD 记录]
## 下周建议（须批准）
1. …
数据缺口：动作明细缺失的 N 次训练未计容量
```

## 纪律（来自 openGym AI Coach 的两条约束）

1. **建议不落盘**：复盘产出的排期调整只出现在复盘回复与 `reports/health/reviews/<YYYY>-W<NN>.md` 中；**用户逐条批准后**才更新 `训练排期_*.md`，并在排期文档注明修订来源。
2. **每条建议带依据**：注明具体记录（日期 + 动作 + 数字），写不出依据的不提。

## 注意事项

- 写复盘报告到 `reports/health/reviews/`（目录不存在则创建），不修改 `domains/` 下任何数据文件。
- 动作明细缺失、`daily_metrics` 缺失时如实标注，不做推算填充；不下医学结论。
- 与医生医嘱冲突（如肌酐复查相关减量）时，医嘱优先，复盘只提示不改判。
