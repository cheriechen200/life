## 二、持仓台账（`domains/invest/holdings.md`）

## 三、单标的深度报告（`domains/invest/briefs/<代码>_<简称>_<YYYY-MM-DD>.md`）

命名例：`sh600000_示例股票A_2025-MM-DD.md`

```
〇、结论（评级 + 行动分类 + 核心理由三条，每条带数据）
一、持仓快照（成本 / 现价 / 数量 / 市值 / 盈亏 / 仓位）
二、基本面（公告原文拆解 + 分季度数据 + 敏感性测算，假设显式列出 + 表观 vs 前瞻估值对照）
三、技术面（均线 / MACD / RSI / KDJ / BOLL + 支撑压力 + 52 周分位）
四、资金面（主力今日 / 5日 / 10日 / 20日 + 超大单 + 融资盘 + 板块）
五、PM 七问（表格逐条回答）
六、多空论点对照（两栏）
七、行动方案
    7.1 执行清单（动作 / 价位 / 数量 / 金额 / 佣金 / 锁定的盈亏）
    7.2 防守线（移动止损 / 次级防线 / 终极防线 / 上方压力）
    7.3 候选替代方向（含相关性说明与"不买清单"）
    7.4 催化剂日历（日期 / 事件 / 影响）
八、数据来源与缺口（来源表 + [MISSING] / [STALE] 逐条）

---
本报告仅供研究参考，不构成个人投资建议，投资有风险，决策需独立。
```

## 五、JSON 落库字段

五类 `type` 的完整字段定义见 [`schema/data-schema.md`](../../../schema/data-schema.md) 的 `## invest 领域` 章节。

通用记录结构（**字段顺序固定，不可调整**）：

```json
{
  "date": "2025-MM-DD",
  "time": "15:00",
  "domain": "invest",
  "type": "position",
  "metrics": {},
  "note": "",
  "source": "",
  "created_at": "2025-MM-DDT16:30:00+08:00"
}
```

`time` 在 `note` / `review` 类型中可省略；`source` 无附件时留空字符串。
