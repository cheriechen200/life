# 取数口径

> `stock-research` 的参考文件。行情 / 财务 / 资金 / 资讯四类数据的取数方式与缺口标记法。

## 一、行情（WeStock CLI）

调用前把 `westock` 所在目录加入 `PATH`。路径按当前环境展开，不写死某台机器：

```bash
# 常规位置（pipx / pip --user 安装）
export PATH="$HOME/.local/bin:$PATH"

# 不在常规位置时先定位，再把所在目录加入 PATH
command -v westock || find "$HOME" -maxdepth 4 -name westock -type f 2>/dev/null
```

未安装则先按 `westock` 官方方式安装，安装后确认 `command -v westock` 有输出再取数。

| 数据 | 命令 | 说明 |
| --- | --- | --- |
| 指数 / 个股 / ETF 行情 | `westock quote sh600000,sz000001,sh512800` | 收盘价、涨跌幅、成交额、52 周高低、PE / PB / 股息率、市值、**5/10/20/60 日涨幅** |
| 技术指标 | `westock technical sh600000 --limit 1` | MA5/10/20/60/120/250、MACD、RSI6/12/24、KDJ、BOLL |
| 资金流向 | `westock fund flow sh600000` | 主力净流入 今日 / 5日 / 10日 / 20日 + 超大单 + 大单 + 中单 + 小单 |
| 板块排行 | `westock sector ranking` | 申万行业涨跌 + 板块主力资金（5日 / 20日） |
| 板块估值 | `westock sector valuation pt01801161` | PE / PB / 股息率 TTM 及其**历史分位** |
| 财报 | `westock finance sh600000 --type income --limit 4 --fields core` | 营收、归母净利、同比、ROE、EPS |
| 披露日历 | `westock disclosure sh600000` | 定期报告预约披露日 |
| 新闻 | `westock news list sh600000 --limit 10` / `westock news detail <news_id>` | 个股资讯与详情 |
| 市场总览 | `westock market-overview` | 市场画像（注意：数据日期常滞后 1 日） |
| 热榜 | `westock hot news` | 全市场热文榜 |

### ⚠️ 三个已知的坑

1. **`westock technical` 的列顺序在批量调用与单标的调用时不同。** 批量为 `date|BOLL_*|DEA|DIF|KDJ|MACD|MA…|close|symbol`，单标的为 `date|close|MA_5…|DIF|DEA|MACD|KDJ|RSI|BOLL_*`。
   → **必须用 `BOLL_MID == MA_20` 做内部一致性校验**，不能凭列位猜。
2. **`westock finance` 对不同行业返回的列集不同**（如银行表缺 `OperatingCost` 等列）。
   → 用 `--fields core` 对齐表头再取值。
3. **ETF 的 `pe_ratio` / `pb_ratio` 恒为 0。**
   → 需要估值时用**成分股代表**（如示例ETF 用工商银行 PB 0.76）或**板块估值**代理，并在报告中注明是代理口径。

### 代码规范

- 必须带市场前缀：`sh` / `sz`。
- 指数：`sh000001`（上证）、`sz399001`（深成）、`sh000300`（沪深300）、`sh000016`（上证50）。
- 板块代码形如 `pt01801161`（电力）、`pt01801194` 是**保险**不是电力 —— 板块代码需从 `sector ranking` 输出中确认，不要凭记忆。

## 二、52 周价格分位（自算）

行情接口**没有** PE / PB 历史分位（个股层面），需自行计算价格位置作为代理：

```
52周分位 = (现价 − 52周低) / (52周高 − 52周低) × 100%
```

**必须在报告中注明**：这是价格位置，**不等于估值分位**，二者不可混同。

板块层面的真实历史分位可从 `westock sector valuation` 的 `PeTTMPct` / `PbLFPct` 字段获得。

## 三、缺口标记法

| 场景 | 标记 | 示例 |
| --- | --- | --- |
| 接口无此数据 | `[MISSING]` | `PE / PB 历史分位 [MISSING]` |
| 数据超过 90 天 | `[STALE]` | `财报截至 2025-06-30 [STALE]（105 天）` |
| 自行建模推算 | `[假设]` | `2026Q3 归母净利 ≈ 118.9 亿 [假设]`（并列明全部假设） |
| 需用户确认 | `[待确认]` | `逆回购占用金额与到期日 [待确认]` |

**财报注意**：A 股定期报告有披露滞后。中报（6-30）在 10 月查询时已超 90 天，须标 `[STALE]`；三季报（9-30）通常在 10 月下旬才披露，此前的季度数据只能靠**公告**（如发电量、产销快报）+ 模型推算。

## 四、公司公告优先

季度经营数据（发电量、产销、销售额）常以**专项公告**先于财报发布，是最高质量的领先指标。

例：`中国示例股票A股份有限公司 2026 年三季度发电量完成情况公告`（公告编号 2025-033，2025-MM-DD），来源为巨潮资讯网 PDF / 中国证券报电子版。

**引用规则**：公告编号 + 发布日期 + 原文数字；新闻转述的公告内容需注明"经新闻转述"，能找到原文则优先用原文。

## 五、输出前的自检清单

- [ ] 每个数字都有来源与日期？
- [ ] 做过 `universe.json` 前缀校验？
- [ ] `[MISSING]` / `[STALE]` / `[假设]` 都标了？
- [ ] 模型假设显式列出了？
- [ ] 结论含行动分类 + 理由（带数据） + 风险 + 止损位？
- [ ] 结尾有免责声明？
- [ ] 52 周分位注明了"是价格位置不是估值分位"？
