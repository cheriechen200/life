# 分析框架

> `stock-research` 的参考文件。三维框架 + PM 七问 + 指标判读口径。

## 一、三维框架

任何一只标的都必须同时过三关，缺一维则结论降级为"观察"。

### 1. 基本面

| 项 | 口径 | 判读 |
| --- | --- | --- |
| 营收 / 利润增速 | 最新财报**单季**同比（不是累计同比） | 累计同比会掩盖拐点；单季才是拐点信号 |
| 拐点识别 | 对比最近 2–3 个单季同比 | 例：H1 净利 +13% 但 Q2 单季 +1.5% → 增速在衰减 |
| 估值 | PE(TTM) / PB / 股息率(TTM) | 必须区分**表观 TTM** 与**前瞻**：TTM 含完整丰水年，前瞻才是未来 |
| 行业景气 | 申万板块涨跌 + 板块主力资金 + 板块估值分位 | 个股跑不赢板块资金方向时，个股逻辑要打折 |
| 利润弹性 | 固定成本占比高的行业（水电、航空、航运），**收入降幅会被放大到利润端** | 例：发电量 -14.89% → 净利 -21% |

**做敏感性测算时必须显式列出假设**，例：
> 假设：①电价不变（长协锁定）②折旧/利息/人工不随产量变动 ③毛利降幅 75% 传导至归母净利 ④投资收益、财务费用同比持平

### 2. 技术面

| 指标 | 判读标准 |
| --- | --- |
| 均线系统 | MA5 > MA10 > MA20 > MA60 > MA120 > MA250 = 完整多头排列；反之空头。**只列趋势，不做预测** |
| MACD | DIF > DEA 且柱体扩张 = 动能增强；零轴上方金叉强于下方 |
| RSI6 | < 20 极度超卖；> 80 超买；**> 90 为极度超买，追高性价比极差** |
| KDJ_J | > 100 短线过热；< 0 短线超卖 |
| BOLL | 收盘价站上上轨 = 短期超买；跌破下轨 = 短期超卖 |
| 52 周分位 | `(现价 − 52周低) / (52周高 − 52周低)`。**注意：这是价格位置，不是估值分位，二者不可混同** |
| 支撑 / 压力 | 支撑取 MA10 / MA20 / MA60 / 前低；压力取前高（双顶 / 三顶）、整数关口、52 周高 |

**量价关系**：价涨量增 = 趋势确认；价涨量缩 = 动能不足；价跌量增 = 抛压。

### 3. 信息面

扫过去 24 小时，按**利好 / 利空 / 中性**三档分类，只保留与持仓 + 候选池相关的。

| 类别 | 例子 |
| --- | --- |
| 宏观政策 | 利率、汇率、财政、行业监管、退税政策 |
| 行业新闻 | 上下游价格（碳酸锂、硅料、运价）、产能、订单 |
| 公司公告 | **发电量 / 产销 / 业绩预告 / 分红——这类是硬数据，权重最高** |
| 资金面 | 主力净流入（今日 / 5日 / 10日 / 20日）、融资盘、板块资金 |
| 外围 | 美股、港股、汇率、大宗。**港股新闻仅作信息面参考，不得据此推荐港股标的** |

**分档后给一句总结**：过去 24h 的信息指向哪条主线？推荐与回避必须围绕该主线，不做逆主线操作。

## 二、PM 七问

产出实质性结论前逐条回答，答不上来的记入「还缺什么证据」：

| # | 问题 |
| --- | --- |
| 1 | **什么被错误定价了？**（答不出 → 标"观察"或"放弃"，无变异认知就没有 alpha） |
| 2 | 当前价格反映了什么？ |
| 3 | 什么能证明论点？ |
| 4 | **什么能推翻论点？**（= `kill_criteria`，写不出说明研究深度不足） |
| 5 | 为什么是现在？（时机） |
| 6 | 什么会改变仓位 / 评级 / 目标价？ |
| 7 | 还缺少什么证据？ |

## 三、资金面判读

| 指标 | 判读 |
| --- | --- |
| 主力净流入 今日 + 5日 + 20日**三期同向为正** | 资金一致性最好，趋势可信度高 |
| 今日为正、5日 / 20日为负 | 反弹但中期在流出 → **超跌修复而非趋势反转** |
| 今日为负、5日 / 10日为正 | 短线获利了结，中期未破坏 → 观察 |
| 超大单持续净流出 | 机构在减 |
| 融资盘连续净卖出 | 杠杆资金撤离 |
| 板块 20 日主力净流出 | 系统性流出，个股alpha 难对冲 beta |

**筹码转移特征**：股价高位 + 主力净流出 + 融资净卖出 = 典型高位换手。

## 四、结论的硬性构成

一条合格的结论 = **行动分类** + **核心理由（带数据）** + **关键风险** + **止损参考位**。

缺任何一项都不输出。

## 五、常见错误清单

| 错误 | 正确做法 |
| --- | --- |
| 用累计同比判断拐点 | 用单季同比 |
| 用 TTM 估值当前瞻估值 | 用业绩推算做前瞻，显式标注 `[假设]` |
| 把 52 周价格分位当估值分位 | 明确注明是"价格位置代理指标" |
| 只看个股资金不看板块资金 | 两者方向一致才可信 |
| 用结果倒推决策质量 | 复盘时评**过程分**而非盈亏 |
| 分散成碎单 | 小额账户笔数越少越省 |
| 把港股新闻当港股推荐依据 | 只作信息面参考 |
