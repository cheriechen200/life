# reflection-log

反思与感悟记录。用户随手写下的一段想法，在这里被结构化保存，成为个人成长轨迹里最私人的部分。

## 触发场景

- 用户说"今天想通了一件事：……""最近状态不太好""记录一下我的感受"
- 用户发来一段没有明确归类的、关于内心的自由文字

## 记录流程

1. 提炼一个简短主题（`theme`），概括这段反思的核心。
2. 判断情绪倾向（`mood`）。
3. 忠实保留原文到 `note`，不压缩、不改写。
4. 若用户提到行动意图，提炼到 `action_intent`。
5. 按 schema 写入 `domains/growth/data/reflections/<YYYY-MM>.json`。

## 输出字段

```json
{
  "metrics": {
    "theme": "关于工作节奏的反思",
    "mood": "calm",
    "action_intent": "试着每天留出 1 小时不被打扰的时间",
    "tags": ["work", "focus"]
  }
}
```

`mood` 取值：`positive`（积极）/ `calm`（平静）/ `mixed`（复杂）/ `low`（低落）/ `anxious`（焦虑）。
`tags` 为自由标签，用于日后检索聚类。

## 用户向回报格式

```
反思已记录 · 2025-10-09
主题：关于工作节奏的反思 · 情绪：平静
行动意图：试着每天留出 1 小时不被打扰的时间
```

## 注意事项

- 这是用户最私密的内容，忠实记录是第一位，不评判、不分析、不给出心理建议。
- 主题与标签用于检索，尽量中性、贴近用户原意。
- 用户若只写情绪不写事由，同样如实记录，不必追问细节。
